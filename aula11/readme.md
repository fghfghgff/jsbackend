O arquivo server.js possibilita 3 tipos de consulta:
-Consultar todos os itens da papelaria;
-Consultar um item específico buscando pelo seu id;
-Consultar todos os itens, ordenados pelo número de vendas.
O arquivo .env descreve a conexão com o Supabase.
O arquivo config/supabaseClient.js configura o cliente do Supabase.
